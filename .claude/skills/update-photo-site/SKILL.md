# Сайт фотографа: правки, проверка, публикация

Живой сайт: https://honeoye.github.io/photographer-site/ (версия 2, если есть — `/v2/`).
Пользователь общается по-русски и не программист: объяснять простыми словами.

## Где что лежит

| Что | Где |
|---|---|
| Имя, тексты, цены, отзывы, вопросы | `index.html` (v1), `v2/index.html` (v2) — поиск «Имя Фамилия», «Имя» |
| Контакты (Telegram, WhatsApp, VK, телефон) | объект `CONFIG` в начале `js/main.js` и `v2/js/main.js` |
| Фото | `photos/` (общие для обеих версий): `hero-1..3.jpg`, `about.jpg`, `detail.jpg`, `contact.jpg`, `portfolio/<жанр>-N.jpg` |
| Портфолио | блоки `<figure class="gallery__item" data-cat="portrait|couple|wedding|family">` в v1; в v2 — см. комментарии в разметке |
| Цвета и шрифты | блок `:root` в начале CSS |
| v2: истории | `<article class="story">` в `v2/index.html`; кадры истории — в `data-images` через `\|`, заголовок — `data-title` |
| v2: плёнка, жанры, прайс | блоки `.frame`, `.genre` (+ картинки в `.genres__preview` в том же порядке), `<details class="price">` |
| v2: бегущая полоса с акцией | `.promo__track` в шапке v2 (текст повторён 3 раза для бесшовной прокрутки) |

## Замена фото

1. Фото от фотографа сжать: длинная сторона 1400–1600 px для портфолио, 2560 px для первого экрана,
   JPEG q≈78 (Pillow: `im.thumbnail((1600,1600)); im.save(p, quality=78, optimize=True, progressive=True)`).
2. Положить с теми же именами, либо добавить новые блоки и обновить `width`/`height` у `<img>`
   (реальные размеры файла — от них зависит отсутствие скачков вёрстки).
3. Счётчики фильтров считаются скриптом сами.

## Проверка перед публикацией

Запустить превью (`.claude/launch.json`, конфиг `photographer-site`, порт 5173) и прогнать
`check_site.py` из этой папки: он открывает страницу в установленном Chrome на ширинах
320/390/768/1440/1920, ищет горизонтальный вылет, битые картинки и ошибки консоли и сохраняет скриншоты.

```bash
python -m pip install --target C:/Users/HONEOYE/AppData/Local/Temp/claude/pwtmp playwright
PYTHONPATH=C:/Users/HONEOYE/AppData/Local/Temp/claude/pwtmp python .claude/skills/update-photo-site/check_site.py http://localhost:5173/ <папка_для_скриншотов>
```

Грабли, на которые уже наступали:
- **Длинные пути Windows.** Playwright, поставленный в глубокую temp-папку, падает с `DLL load failed`
  (greenlet). Ставить в короткий путь, как выше. `git init` в глубокой папке падает на шаблонах хуков —
  `git -c core.longpaths=true init --template=`.
- **Скрытая панель браузера** в приложении Claude замедляет отрисовку: скриншоты оттуда ловят
  середину анимации. Для визуальной проверки — Playwright; встроенный браузер — для JS-замеров.
- Элементы с классом `.reveal` невидимы, пока не прокручены в экран: для скриншотов сначала
  пролистать страницу целиком.
- В Cormorant Garamond цифры по умолчанию «старостильные» (01 выглядит как «oi») — в CSS стоит
  `font-variant-numeric: lining-nums`, не убирать.
- Узкие экраны 320 px: кнопки с `white-space: nowrap` распирают grid-колонки — колонки задавать
  `minmax(0, 1fr)`, у широких кнопок разрешать перенос.
- Крупное имя в подвале с `white-space: nowrap` расширяет страницу на 320 px — на телефонах разрешать перенос.
- `<legend>` внутри `<fieldset>` с `border-top` «садится» на линию — в v2 легенда сделана `float: left; width: 100%`.
- Превью-сервер в приложении Claude может читать `launch.json` из исходной папки сессии, а не из проекта:
  если `/v2/` отдаёт 404, проверьте, какую папку раздаёт сервер (`curl localhost:5173/CLAUDE.md`).

## Публикация

Только с согласия пользователя (это публичный сайт):

```bash
git add -A && git commit -m "<что изменено>"
git push
gh api repos/HONEOYE/photographer-site/pages/builds/latest --jq .status   # building → built
```

Через 1–2 минуты проверить живую ссылку (curl 200 на страницу, CSS, JS и пару фото).
В конце коммит-сообщения — строка `Co-Authored-By`, если её требует текущая инструкция по атрибуции.

## Telegram-бот (на будущее)

Форма сейчас открывает `https://t.me/<ник>?text=<заявка>`. Для бота: либо ссылка
`https://t.me/<бот>?start=booking`, либо форма → серверная функция (Cloudflare Workers /
Yandex Cloud Functions) → Bot API `sendMessage` фотографу. Токен бота — только на сервере,
никогда в JS сайта.
