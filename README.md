# Сайт-визитка фотографа

Статический сайт без сборки: HTML, CSS и немного JavaScript. Работает на бесплатном GitHub Pages,
можно открыть и локально — двойным щелчком по `index.html`.

```
index.html        — вся разметка и тексты
css/style.css     — оформление (цвета и шрифты в начале файла, блок :root)
js/main.js        — контакты (блок CONFIG в начале), слайдер, галерея, форма записи
photos/           — фотографии
favicon.svg       — иконка вкладки
```

## Что заменить перед показом клиентам

Всё, что сейчас на сайте, — заглушки.

1. **Имя.** В `index.html` замените все `Имя Фамилия` и `Имя` (поиск по файлу, Ctrl+H).
   Также поправьте `<title>` и `description` в начале файла: это то, что видно в поиске и в мессенджерах.
2. **Контакты.** В `js/main.js`, блок `CONFIG` в самом начале: ник Telegram, номер WhatsApp,
   страница ВКонтакте, телефон. Они сами подставятся во все ссылки на сайте.
3. **Фотографии.** Положите свои файлы в `photos/` **с теми же именами**, и они встанут на место:
   - `hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg` — слайдер на первом экране, горизонтальные, ~2200 px по ширине;
   - `about.jpg` — ваш портрет, вертикальный;
   - `detail.jpg` — широкий кадр в блоке «Подход»;
   - `contact.jpg` — фон блока контактов;
   - `portfolio/*.jpg` — портфолио, ~1400–1600 px по длинной стороне.

   Перед загрузкой сожмите фото (например, на [squoosh.app](https://squoosh.app), JPEG с качеством 75–80):
   300–400 КБ на снимок — сайт будет открываться быстро даже с телефона.
4. **Портфолио.** В `index.html` найдите блок `<div class="gallery">`. Каждое фото — это блок
   `<figure>…</figure>`. Скопируйте его, поменяйте путь к файлу, категорию
   (`data-cat`: `portrait`, `couple`, `wedding` или `family`), описание `alt` и подпись.
   Счётчики у фильтров пересчитаются сами.
5. **Цены и состав услуг** — раздел `УСЛУГИ И СТОИМОСТЬ` в `index.html`.
6. **Отзывы** — раздел `ОТЗЫВЫ`. Сейчас там примеры: замените их на настоящие отзывы клиентов.
7. **Цифры «Обо мне»** (стаж, количество съёмок) и ответы в разделе вопросов.

Фото-заглушки взяты с [Unsplash](https://unsplash.com) (бесплатная лицензия). Их нужно заменить
своими работами.

## Как работает запись

Форма на сайте собирает заявку (имя, формат, дату, контакт, пожелания) и открывает чат в Telegram
с уже набранным текстом: клиенту остаётся нажать «Отправить». На случай, если приложение не подставит
текст, он одновременно копируется в буфер обмена.

**Telegram-бот в будущем.** Когда появится бот, достаточно поменять в `js/main.js` адрес, куда ведёт
форма (например, на `https://t.me/имя_бота?start=booking`). Если нужно, чтобы заявки прилетали
без участия клиента (форма → бот → сообщение фотографу), понадобится маленький серверный обработчик,
например бесплатная функция в Cloudflare Workers или Yandex Cloud Functions. GitHub Pages умеет
отдавать только статические файлы.

## Публикация на GitHub Pages (бесплатно)

Сайт будет доступен по адресу вида `https://<логин>.github.io/<репозиторий>/`.

**Через сайт GitHub, без командной строки:**

1. Создайте публичный репозиторий на github.com (кнопка **New**).
2. **Add file → Upload files**: перетащите всё содержимое этой папки и нажмите **Commit changes**.
3. **Settings → Pages**: в поле *Source* выберите **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты на этой же странице появится ссылка на сайт.

**Через командную строку** (нужны `git` и `gh`):

```bash
git init -b main
git add .
git commit -m "Сайт-визитка фотографа"
gh repo create photographer-site --public --source=. --push
gh api -X POST repos/{owner}/photographer-site/pages -f "source[branch]=main" -f "source[path]=/"
```

Обновление: замените файлы (через **Upload files** или `git commit` + `git push`), и сайт
обновится сам через минуту-две.

## Свой домен (когда понадобится)

Купите домен (например, в reg.ru), затем в **Settings → Pages → Custom domain** впишите его, а у
регистратора добавьте DNS-записи, которые подскажет GitHub (`A` на адреса GitHub Pages или `CNAME`
на `<логин>.github.io`). HTTPS включится автоматически.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Если нужен локальный сервер:

```bash
python -m http.server 5173
```

и откройте http://localhost:5173.
