# Сайт-визитка фотографа

Статический сайт (HTML/CSS/JS без сборки) для друга пользователя — фотографа (мужчина, Москва).
Опубликован на GitHub Pages: https://honeoye.github.io/photographer-site/
Репозиторий: https://github.com/HONEOYE/photographer-site, ветка `main`, Pages собирается из корня.

Общение с пользователем — на русском.

## Структура

- `index.html`, `css/style.css`, `js/main.js` — версия 1 (тёплый «журнальный» дизайн, светлый фон, Cormorant Garamond + Manrope).
- `v2/` — версия 2 дизайна (если есть): своя разметка и стили, фото берёт из общей папки `../photos/`.
- `photos/` — общие фото. Сейчас это заглушки с Unsplash; файлы заменяются на работы фотографа с теми же именами.
- Контакты задаются в одном месте — объект `CONFIG` в начале `js/main.js` (и в `v2/js/main.js`), ссылки подставляются по атрибуту `data-contact`.
- `README.md` — инструкция для фотографа (как менять фото, тексты, публиковать).

## Что ещё заглушки

Имя («Имя Фамилия»), ник Telegram (`username`), WhatsApp, VK, телефон, город, цены, цифры «Обо мне»,
отзывы (выдуманные примеры — заменить настоящими до показа клиентам), фото.

## Запись

Форма собирает заявку и открывает `https://t.me/<ник>?text=...` + копирует текст в буфер.
В будущем пользователь, возможно, захочет Telegram-бота для записи: GitHub Pages статичен, поэтому
для автоматической доставки заявок понадобится серверная функция (Cloudflare Workers / Yandex Cloud Functions).

## Как работать

- Превью: конфиг `photographer-site` в `.claude/launch.json` (python http.server, порт 5173).
- Типовые задачи (заменить заглушки, проверить на экранах, опубликовать) — скилл `update-photo-site`
  в `.claude/skills/`.
- Публикация = `git push` в `main`; Pages пересобирается за 1–2 минуты. Пушить только с согласия пользователя.
